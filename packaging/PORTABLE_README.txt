AIGrader Windows x64 Portable
=============================

1. 解压整个 AIGrader-Windows-x64 文件夹，不要只复制 AIGrader.exe。
2. 双击 AIGrader.exe；无需安装，也不需要管理员权限。
3. 首次使用前，在 %LOCALAPPDATA%\AIGrader\.env 写入：
   DEEPSEEK_API_KEY=你的密钥
4. 任务、标定、日志、数据库和异常截图保存在：
   %LOCALAPPDATA%\AIGrader
5. 更新时只替换程序文件夹。不要删除上述用户数据目录。

推荐 Windows 10/11 x64、显示缩放 100%，并保持浏览器及智学网页面布局固定。
